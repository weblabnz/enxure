## Recapturing them

Settings > Data Management > Screenshots captures these straight from the browser tab, no separate tool needed, and overwrites the matching file here in place. The page list and filenames come from [`../../src/lib/screenshot_manifest.json`](../../src/lib/screenshot_manifest.json).

Resize the window first — it captures exactly what's on screen. Requires HTTPS (or `localhost`); one share-this-tab prompt covers every selected page.
